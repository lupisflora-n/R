# 実機確認シート（Codexが試験用URLと架空サンプルを用意する）

現在利用可能な端末: Androidのみ（2026-10-06本人回答）。機種/OS/Chrome版/メールは開始時に記録。iPhoneはNEEDS_HUMAN_TESTのまま。
試験URL / 日時 / 試験者匿名ID:
各手順の結果: PASS / FAIL / NOT_RUN。失敗時は手順番号、期待、実際、再現回数を追記。
使いやすさの初見試験は別紙USABILITY_SESSION.mdを使い、操作説明を先に見せない。

1. 正式な試験URLを端末ブラウザーで開く。機能と保存の注意が読めるか。
2. 指定の架空書式を1枚撮る。横向きや戻る操作でも下書きと日付が正しいか。
3. 四隅を動かし、白黒とカラーを切り替える。小数点・小さい数字・薄字が最終PDFに残るか。
4. PDFを作り、次の「共有して送る」を押す。メールへ正しい名前/枚数で添付されるか。
5. 自分の確認用アドレスに送る（最終送信は本人）。受信側でPDFを開く。
6. アプリを閉じて開く。文書とPDFが残るか。10枚でも確認する。
7. 復元用ZIPを外に保存し、別の検証用保存領域へ読み込む。元のデータを消して試さない。
8. Codexが用意する新版に更新。文書が消えず、作業中に勝手に更新されないか。

全部を一度に要求せず、M0では1〜5、後続で6〜8に分ける。結果はOK/NGと気づいた点だけでよい。CodexがEVALSへ転記し原因分析を担当。
