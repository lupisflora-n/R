# 日付スキャン｜iPhone・Android / 基本無料 / 監督型開発
設計版 2.0 | 実装更新 2026-10-03 | ローカル実装済み / ブラウザーと実機の受入れ未完了

## 現在の実装

写真の原本・下書き保存、手動四隅の透視補正、白黒/グレー/カラー/強い白黒、回転、日付・名前管理、選択順の1〜10枚PDF、完成PDFの表示、File共有とファイル保存、日付単位の復元ZIP、更新待機を実装しました。

21件の合成データによる処理・形式・更新制御検査を実行しています。ブラウザーのIndexedDB実装、画面全体、カメラ、HEIC、メール添付、実機の10枚処理、オフラインと旧版から新版の実動作は未合格です。公開済みの完成アプリではありません。

ネットワーク権限付き実行が2回応答待ちになったため、現環境にある無料ライブラリを `vendor/` へ版・ライセンス・ハッシュ付きでコピーしました。React/Vite/Dexie/OpenCVの追加取得は未実施です。暫定実装はTypeScriptとブラウザー標準の画面・IndexedDB・Workerによる透視補正を使います。この技術上の変更は `DECISIONS.md` に記録しています。

## ローカルで起動する

Node.js 24.3以降が必要です。依存インストール・認証・外部公開をせずにビルドと処理の検査ができます。

```sh
npm ci --offline --ignore-scripts
npm test
npm run lint
npm run build
npm run dev
```

最後のコマンドは `127.0.0.1:4173` にだけ待受けます。このクラウド実行サンドボックスでは待受けとChromium起動がEPERMで拒否され、実行確認できませんでした。通常のWindowsターミナルからはこの経路を検査できます。`npm run lint` / `npm run check:syntax` は構文・危険パターン検査であり、TypeScriptの型検査の代わりとは扱いません。

`npm run test:e2e` はPlaywrightが別途利用できる環境向けです。既定はローカルのビルド資源を通信なしでブラウザーに渡し、Service Workerを無効にして画面/IndexedDBを検査します。実サーバーのPWA検査には `DOCSCAN_E2E_URL` を起動済みローカルサーバーに指定します。実iPhoneの合格は別途必要です。

## 安全上の暫定上限

- 写真1枚は50 MiB以下、確定処理は24MP以下。超過時は縮小せず停止し、受取り済み原本を保持します。
- 1PDFは10枚まで。20枚は実機検証後の拡張です。
- 復元用ZIPは1部50 MiB以下、1部10枚まで。まとめて復元する全体は圧縮・展開とも100 MiB以下です。書出しにも対応する上限を適用します。
- 100 MiBを超える日付の段階的復元は次の実装です。ZIPに過去PDFの完成バイトは含みますが、過去の全編集画像・履歴を再構成する機能ではありません。

実機の確認手順は `docs/DEVICE_TEST_GUIDE.md`、再開点は `STATE.md`、検査範囲と未検証は `EVALS.md` を参照してください。

## 最初に
この版を現行の設計正本とする。v1のAndroid専用、ML Kit、Room、Play配布、監査だけで止める開始指示は採用しない。旧資料を削除せず参考保管し、Codexの有効な指示に混在させない。

かっしーの確定条件は「iPhoneでも使える」「基本無料運用」「Codexへ渡した後は本人が確認と判断に集中」。今回の設計判断は、**端末内処理のPWAを、Cloudflare Pagesの無料枠で配布する**こと。技術方式はこの条件からの提案であり、実機検証済みの事実ではない。

PWAとは、Webサイトをホーム画面に追加してアプリのように使う方式。App Store / Google Playへの登録を初版の前提にしない。アプリの利用者にCodexやChatGPTの契約は不要。開発時のCodex利用枠・通信・端末・保守の労力は「無料アプリ運用」と別。

## 引き継ぎ方
1. このフォルダの内容を対象リポジトリへ配置する。既存のAGENTS.mdや設定がある場合はCodexに差分統合を任せ、無条件で上書きしない。別案件のリポジトリを勝手に選ばない。
2. `CODEX_START_PROMPT.md` の本文をCodexへ渡す。安全な実装作業は段階ごとに毎回許可を取り直さず進める指示になっている。
3. かっしーへの報告は `templates/DIRECTOR_REPORT.md`。環境の初回認証、iPhone実機確認、公開など必要な場面だけ判断を返す。
