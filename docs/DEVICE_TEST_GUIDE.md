# 日付スキャン v2 の実機確認手順

この手順は匿名の架空文書だけで行います。検証URLはまだありません。外部公開と認証は監督承認後に別作業として進めます。実際の文書・氏名・住所・署名・印影を開発者へ送る必要はありません。

## 確認する端末

iPhone Safariの通常画面とホーム画面版、Android Chromeの通常画面とホーム画面版を分けて記録します。機種、OS、ブラウザー、メールアプリ、起動形態、アプリ版、確認日を `templates/DEVICE_CHECK.md` に記録してください。別ブラウザー・別URL・通常画面/ホーム画面版で同じ保存領域になるとは限りません。

## 写真1枚からメール添付

1. 「紙を撮影」を押し、架空の紙を撮影します。戻ると「下書き保存」が表示されることを確認します。
2. 四隅の1〜4を紙の角へ移動します。矢印で細かく直せることを確認します。
3. 「加工後を確認」を押し、小数点・薄字・数字・架空の赤い印が欠けないか原本と比べます。欠ける場合はカラーへ戻します。
4. 「編集を保存」を押します。日付一覧に「編集済み」が出ることを確認します。
5. 写真にチェックし、PDFの名前を設定して「1枚でPDFを作成」を押します。完成PDFに紙全体・細字・数字があることを確認します。
6. 別の「共有して送る」ボタンを押し、メールを選びます。添付の名前・宛先を自分で確認します。試験送信する場合は自分の受信先を使い、受信したPDFのページと内容を確認します。
7. 一度共有を取消し、保存済みPDFが残り、アプリが「送信済み」と表示しないことを確認します。

## 途中終了と保存

写真を下書き保存した後、編集せず閉じて開き直します。原本が残り、編集を再開できることを確認します。カメラや共有画面に30秒以上滞在した後の復帰も確認します。容量不足を試す場合はテスト専用の保存領域を使い、普段の文書を削除しないでください。

## 復元

1. 「この日付の復元用ZIPを作る」を押し、表示された全ての部を端末の外へ保存します。ZIPは暗号化されません。
2. テスト専用の別ブラウザーまたは保存領域で「復元用ZIPを読み込む」を押し、全ての部を選びます。
3. 日付・枚数・PDF件数を確認して追加します。原本・現在の編集・並び順・完成PDFが一致することを確認します。
4. 同じZIPを再度追加し、文書が重複しないことを確認します。普段の保存領域を初期化して試験しないでください。

## オフラインと更新

正式な試験URLで資源準備を確認した後、機内モードで写真→編集→PDFまで試します。メールの配送は別です。旧版で文書を保存してから新版を用意し、編集中・未保存写真あり・PDF処理中は更新が適用されず、作業終了後だけ更新されることを確認します。更新後に原本・日付・順序・完成PDFが残ることを確認します。

## 判定

実機の画質・撮影・添付・保存・更新が通るまでD01/D02/H01/U01/U02は合格にしません。実機の10枚PDFを検査するまで、合成小画像の10枚PDFだけで処理時間・メモリ・品質を保証しません。
