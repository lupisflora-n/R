# docPDF｜文言方針

2026-10-13。本人の「説明テキスト・ボタン名のAI感をなくし、一般的なアプリと同じ自然な使用感にする」という指示に基づく。最新プレビューへ反映。公開アプリへの反映はデザイン実装時。

## 基準

- 操作を直接表す。宣伝文句、励まし、造語、不要なブランド語を操作画面に置かない。
- 画面名とボタン名を揃える。説明でボタンの場所を補う構成を避ける。
- 常時表示の重複説明を減らす。必要な案内は初回、ヘルプ、失敗、確認の場面で短く出す。
- 成功は実際の完了後だけ表示。OS共有への引渡しをメール送信完了と呼ばない。
- 保存の場所や暗号化など、利用者の判断に必要な情報は残す。端末内保存を永久保存や自動バックアップと呼ばない。

## 主な表示名

| 役割 | 表示名 | 条件・意味 |
|---|---|---|
| カメラ起動 | 撮影 | 写真撮影の入口 |
| 画像追加 | 写真を選ぶ | 既存の画像入力。PDF取込の追加ではない |
| 四隅の画面 | トリミング | 原本の四点調整 |
| 四隅の決定 | 次へ | 決定成功後に調整へ進む |
| 四隅の初期位置 | リセット | 原本削除ではない |
| 色調整の画面 | 調整 | 「色加工」「文書化」を置き換える |
| フィルター | 白黒 / カラー | 現行2択、白黒は連続階調 |
| 白黒調整量 | バランス | 調整1本。明るさ/コントラスト個別UIは追加しない |
| 原本比較 | 元の写真 | 編集の取消と混同しない |
| 写真回転 | 回転 | 90度回転。支援技術向け名称では向きも伝える |
| 名前編集 | 名前を変更 | 入力欄で対象を明示 |
| 編集を保存 | 保存 | 保存完了後に一覧へ戻る |
| PDF画面の入口 | PDF作成 | 選択枚数を併記 |
| PDF生成 | 作成 | PDF作成画面内で使用 |
| OS共有へ渡す | 共有 | 「送信」「送信完了」としない |
| PDF外部保存 | 保存 | PDF画面内で使用、共有とは別 |
| 写真削除 | 削除 | ごみ箱へ移動。即時完全削除ではない |
| ごみ箱から戻す | 元に戻す | 完全削除と区別 |
| ZIP出力 | 書き出す | 日付の写真・PDF・削除済みを含むバックアップ |
| ZIP取込 | 復元 | 検証後の追加復元を維持 |
| 保存保護の確認・要求 | 保存設定 | ブラウザーへの要求結果を表示、永久保持を保証しない |
| 操作説明 | ヘルプ | 宣伝文句を置かない |

「その日の紙を文書に」等のスローガンは表示しない。「作成後にPDFを確認できます」のような自明な常設説明も除く。「四隅をドラッグして調整」は必要な操作案内として1箇所に残す。

## 状態と確認の例

| 場面 | 文言例 | 実装条件 |
|---|---|---|
| 書類0枚 | 書類がありません | 撮影/写真選択を同画面に置く |
| PDF0件 | PDFがありません | 未作成と削除済みを混同しない |
| 写真処理中 | 調整中… | 未反映なら保存無効、前のプレビューを維持 |
| PDF生成中 | PDFを作成中… | 重複生成を防ぐ |
| 保存失敗 | 保存できませんでした | 原本/入力を保持、次の操作を添える |
| 選択超過 | 一度に選べるのは10枚までです | 勝手に対象を落とさない |
| ごみ箱へ移動 | ごみ箱に移動しました | DB成功後。元に戻すを併記できる |
| 完全削除確認 | この写真を完全に削除しますか？ | 取り消せないことを明記、PDF参照中は不可 |
| 共有取消 | 完了メッセージなし | 取消を送信完了と表示しない |
| バックアップ | バックアップは暗号化されません。 | 書出し時に判断できる位置に表示 |

状態例は全体展開/実装時の基準。未作成の状態を実装済みとは扱わない。
