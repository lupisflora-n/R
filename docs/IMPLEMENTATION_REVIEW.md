# 日付スキャン v2 の読取りレビューと修正

2026-10-03、別コンテキストのレビュー担当1名が要求と差分を読取りで確認しました。追加の担当・有料APIは使用していません。レビュー担当はファイル編集・ネット通信・公開をしていません。実装担当のアプリコード変更もワークスペース内のみです。

## 指摘と修正

- 複数のZIP部で同じ画像IDに別内容があれば、全体のハッシュ・役割・MIME・サイズを照合して拒否します。
- manifestも上限付きのストリームで読み、宣言サイズを偽った展開を途中で止めます。合成ZIPで拒否を再確認しました。
- 編集設定と名前は一度だけ複製し、確定出力と同じ設定をトランザクションで保存します。処理中の編集操作を無効にします。
- 写真の保存後に、チェックボックスと再編集ボタンの有効状態を再計算します。
- 復元する日時・PDFのスナップショットIDを検査します。不正な値が一覧表示を壊す前に拒否します。
- 更新のAPPLY要求を送る前に画面全体の新しい作業を停止します。遅延応答と先行controllerchangeの合成検査を追加しました。
- カメラからの復帰・画面復帰時に書込みリースを取り直します。期限切れの旧世代の保存は拒否します。
- ZIPは展開後も全体100 MiBで停止します。書出しも対応する上限を守り、復元不能のZIPを準備しません。大容量の段階的復元は未実装です。
- 未保存の受取写真を再試行用に保持し、その間は新しい撮影・日付変更・更新を停止します。画面を閉じることへの注意も含めます。ブラウザーの強制終了まで保護できるとは説明しません。
- 「今日」も処理中・編集中は無効にし、表示日付と実際の保存先がずれないようにします。
- PDFと編集画像は確定保存の直前にも取消を検査します。

## 検査の限界

読取りレビューとNodeの合成検査です。ブラウザーUI、実際のIndexedDBトランザクション、容量不足、OS終了、カメラ・HEIC・メール添付は検査していません。公開を許可するレビューではありません。未合格は `EVALS.md` に残しています。

最後の書出し総量・未保存写真・「今日」の追加修正は実装担当が差分を確認しました。レビュー担当の最終応答は修正説明に基づくもので、その最後の差分を別担当が再読込みして合格にしたとは扱いません。
