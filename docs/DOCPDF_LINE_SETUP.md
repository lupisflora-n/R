# docPDF｜公開後のLINE設定と実機確認

2026-10-08。この手順は準備資料。サイト公開・LINEメニュー反映は未実施。

## いま本人側で済んでいること

公式アカウント「docPDF」、プロバイダー「Rプロジェクト」、LINEログインチャネル「docPDF」。チャネルはDevelopingのままで構わない。今回のURL入口方式はそのチャネル・LIFFを使わないため、追加設定や秘密の提出は不要。

## 先に行う公開

1. 承認後、新規検証専用Cloudflare Pages（候補 `docpdf-line-test`）へ `release/docpdf-line-preview-<build>.zip` を静的Direct Upload。既存 `docscan-v2-test` にはアップロードしない。有料機能や文書サーバーを追加しない。
2. ログイン・アカウント選択は本人が操作。今のCodexにはCloudflareやLINEの画面操作用接続がないため、操作代行はできない。パスワードやトークンをチャットへ送らない。
3. 返された固定HTTPS URLでbuild.jsonを照合し、ヘッダー・ブラウザーE2Eを検査。新規サイト作成前にURLを存在するものとして配らない。
4. 専用originを確定したら、`node scripts/prepare-line-links.mjs <実際のHTTPS origin>` で貼付用URLを作る。コードやPDF、顧客情報をURLへ含めない。

## 公式アカウントのリッチメニュー

以下は公式マニュアルで確認した操作。本人の画面で文言や順序が違う場合は、その画面を確認してから案内する。

1. LINE Official Account Managerで**docPDF**を選ぶ。別の公式アカウントを変更しない。
2. 「リッチメニュー」→「作成」。小サイズ・左右2区画のテンプレートを選ぶ。
3. `design/line/rich-menu.png` を背景画像に設定する（2500×843、PNG、1MB未満）。
4. 左はURLアクション、ラベル「docPDFを開く」、リンク生成結果の `app` URLを貼る。
5. 右はURLアクション、ラベル「使い方と安全」、リンク生成結果の `help` URLを貼る。
6. 管理用タイトル「docPDF 検証用」、メニューバー文言「書類をPDFに」。試験期間と表示設定は本人が確認する。公開前に下書きで内容を確認する。
7. LINE自身のあいさつメッセージを使うなら、下記の文を本人が設定・承認する。Codexが勝手に送信や配信をしない。

> docPDFは書類をPDFにするための入口です。下の「書類をPDFに」からブラウザーを開いてください。写真やPDFは、このトークには送らないでください。検証中は架空の書類を使用します。

リッチメニューがない間は、本人用の試験として生成したapp URLを自分のLINEのKeepメモ等へ置き、リンクから起動を確認できる。顧客情報をメモやトークへ置かない。メニューの合格確認は後で別途行う。

## Androidの最初の試験

実書類を使わない。機種・Android・Chrome・LINE・メールアプリの版、実行日、公開buildを記録。

1. docPDFの左メニューを押す。LINE内ではなくChrome等へ移ったか確認。切替案内が出たらリンクを押し、移らなければURLをコピーしてChromeへ貼る。ここでは書類を取込まない。
2. 紙に `TEST ONLY / 0.05 / 123.45 / 001 / 008` と枠を書き、「紙を撮影」。下書き保存の表示を確認。
3. 四隅を合わせ、「加工後を確認」。数字・小数点・薄字・枠を原本と比較。欠けたらカラーへ戻す。
4. 「編集を保存」→写真にチェック→「1枚でPDFを作成」。PDFの全文とページ端を確認。
5. 「ファイルに保存」し、実際のファイルを開く。次に「共有して送る」から本人宛メールへ添付・送信。受信側でPDF名・1ページ・内容を確認。
6. 共有取消を試し、PDFが残り「送信済み」と表示されないことを確認。
7. ブラウザーを閉じ、LINEメニューから同じURL・同じブラウザーを開いて、原本・編集・PDFが残るか確認。

返す情報は各手順のOK/NGと迷った箇所だけ。実書類画像や顧客情報を開発者へ送らない。iPhone、10枚、復元、オフライン、旧→新更新は後続ゲートで、1枚成功から合格を推測しない。

## 取り消す場合

docPDFのメニューを下書き／非表示へ戻すか、入口リンクを外す。本線のサイトや端末DBを削除しない。試作データの保存・削除は本人が内容を確認して行う。ホストを戻すことと端末内データの巻き戻しは別。
