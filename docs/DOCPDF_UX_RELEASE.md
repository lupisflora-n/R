## 同じURLへの更新手順

1. Cloudflare Workers & Pagesで **docpdf-line-test** を開く。
2. **Create deployment** で上記ZIPを選び、Productionへ配信。既存docscan-v2-testは対象外。
3. 固定URL `https://docpdf-line-test.pages.dev/build.json` でbuildを照合。固有deployment URLでは文書の保存領域が異なるので日常の起動に使わない。
4. 作業を保存してアプリを開き直す。更新通知が出たら未保存編集・処理・別タブがない状態で適用。データ/キャッシュ削除はしない。

この環境にはCloudflareの認証・管理画面操作接続がないため、配信完了とは記録していない。公開先と独立GitHub保存は既に承認済みで再承認は不要。

## 架空3枚の実機確認

- 四隅が欠けず見えるか。番号を選択・移動して次へ進めるか。
- 白黒/カラーを選択→加工後を確認→原本比較→保存。色調を変えたら確認し直さないと保存できないか。
- 編集途中で閉じても下書きが残るか。撮影/取込のどちらも削除→ごみ箱→元に戻せるか。
- PDFに使っていない架空写真だけ完全削除。完成PDF使用写真は完全削除不可の理由が出るか。
- 3枚の選択順・PDF文字を確認し、メールの宛先・添付を確認して送信。アプリは共有要求を送信済みにしない。
- 再起動後の保存、旧版からの更新、復元ZIPのごみ箱保持を確認。iPhone・文字拡大・320px幅は別途確認。
